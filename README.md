ESP32-C3-XIAO-with-GPS-MAX30102-TMP117-SIM800L
In this project we working on prototype of gps band.
For that we are taking the data from GPS, MAX30102, TMP117, MPU6050.
And send it thorough MQTT protocal via ESP32-C3-XIAO for connectivity i use SIM800L.
SIM800L is connected through UART and same for GPS.
And all sensor is connected through I2C bus.
For broker i use Adafurit Sever.
